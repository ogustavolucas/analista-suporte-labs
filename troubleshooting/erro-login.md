# Troubleshooting – Erro de Login

## Descrição
Procedimento de verificação para falhas de autenticação reportadas por usuários.

## Possíveis causas
- Credenciais incorretas
- Usuário bloqueado ou inativo
- Falha no serviço de autenticação
- Indisponibilidade temporária do sistema

## Passos de verificação
1. Confirmar usuário e senha com o cliente
2. Verificar status da conta no sistema
3. Testar acesso em outro navegador ou dispositivo
4. Validar status dos serviços
5. Escalar para o time responsável, se necessário
